# ساخت دستی فایل اجرایی ZhaniyaTray.exe — راهنمای کامل قدم‌به‌قدم

این راهنما برای وقتی است که می‌خواهید **خودتان دستی** پیش‌نیازها را نصب کنید
و بعد فایل اجرایی برنامه‌ی سینی ویندوز (`ZhaniyaTray.exe`) را بسازید.
هر دستور را دقیقاً تایپ یا کپی کنید.

---

## ۱. نصب پیش‌نیازها

### ۱-۱. نصب Python

1. به <https://www.python.org/downloads/> بروید و دکمه‌ی زرد **Download Python 3.x.x** را بزنید.
2. نصب‌کننده را اجرا کنید و **حتماً** تیک گزینه‌ی زیر را بزنید (خیلی مهم):

   ☑ **Add python.exe to PATH**

   > ⚠️ اگر این تیک را نزنید، دستور `python` در CMD شناخته نمی‌شود.
   > اگر قبلاً بدون تیک نصب کرده‌اید، نصب‌کننده را دوباره اجرا و گزینه‌ی Modify را بزنید،
   > یا Python را حذف و دوباره با تیک نصب کنید.

3. تا انتها Next کنید تا نصب تمام شود.

> ⚠️ اگر فقط «Python از Microsoft Store» را دارید، کافی نیست؛ آن یک میان‌بر
> بی‌فایده است. حتماً از سایت python.org نصب کنید.

### ۱-۲. بررسی نصب Python

یک پنجره‌ی **Command Prompt** باز کنید (کلید Win → تایپ `cmd` → Enter) و تایپ کنید:

```
python --version
```

باید چیزی مثل `Python 3.12.x` چاپ شود. سپس:

```
python -m pip --version
```

باید نسخه‌ی pip چاپ شود. اگر هر دو جواب دادند، به بخش ۲ بروید.

### ۱-۳. اینترنت

برای نصب بسته‌ها با pip اینترنت لازم است (فقط همین یک مرحله اینترنت می‌خواهد).

---

## ۲. نصب دستی بسته‌های موردنیاز

پنجره‌ی CMD را در پوشه‌ی `connector` باز کنید:

1. پوشه‌ی `connector` را در File Explorer باز کنید.
2. در **نوار آدرس** بالای پنجره تایپ کنید `cmd` و Enter بزنید.
   (یک CMD سیاه دقیقاً در همان پوشه باز می‌شود.)

حالا یکی‌یکی این سه دستور را بزنید (هر کدام چند دقیقه طول می‌کشد):

```
python -m pip install --upgrade pip
```

```
python -m pip install pystray pillow pyinstaller
```

> اگر pip خطای SSL یا Proxy داد: اینترنت/فیلترشکن را بررسی کنید و دوباره بزنید.

---

## ۳. ساخت آیکون برنامه

در همان پنجره‌ی CMD (پوشه‌ی `connector`):

```
python make_icon.py
```

باید بگوید `ساخته شد: ...icon.ico`. اگر این فایل ساخته شد، ادامه دهید.

---

## ۴. ساخت فایل اجرایی (EXE)

```
python -m PyInstaller --noconfirm --onefile --windowed --name ZhaniyaTray --icon icon.ico tray_app.py
```

> ⏳ این مرحله ۲ تا ۵ دقیقه طول می‌کشد و متن‌های زیادی چاپ می‌شود؛ طبیعی است.
> در پایان باید `Successfully built ...` یا `Building EXE ... completed successfully` ببینید.

فایل ساخته‌شده: `connector\dist\ZhaniyaTray.exe`

---

## ۵. آماده‌سازی پوشه‌ی نهایی

این دو دستور را بزنید تا فایل‌های لازم کنار exe کپی شوند:

```
copy zhaniya_connector.py dist\
```

```
copy config.example.json dist\
```

ساختار نهایی پوشه‌ی `dist`:

```
dist\
 ├─ ZhaniyaTray.exe        ← برنامه‌ی اصلی
 ├─ zhaniya_connector.py   ← هسته‌ی کانکتور
 └─ config.example.json    ← نمونه‌ی تنظیمات
```

> پیشنهاد: کل پوشه‌ی `dist` را به مسیر دائمی مثل `C:\ZhaniyaTray` منتقل کنید.

---

## ۶. اجرای برنامه

1. `ZhaniyaTray.exe` را اجرا کنید → آیکون کنار ساعت ویندوز ظاهر می‌شود.
2. راست‌کلیک روی آیکون → **تنظیمات** → اولین بار: نام کاربری و رمز دلخواه بسازید.
3. تب «اتصال ابری»: آدرس هاست + کلید/رمز دستگاه (از صفحه‌ی «دستگاه‌ها»ی داشبورد).
4. تب «اتصال به ژانیا»: آدرس ZhaniyaApi و کاربر/رمز ژانیا.
5. **ذخیره** کنید و تیک **«اجرا همراه با ویندوز»** را بزنید.

---

## ۷. عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `'python' is not recognized` | تیک Add to PATH را نزدیده‌اید — نصب را Modify کنید یا دوباره نصب کنید |
| `No module named pip` | `python -m ensurepip --upgrade` سپس دوباره دستورهای بخش ۲ |
| خطای pip در نصب بسته‌ها | اینترنت/پروکسی؛ یا `python -m pip install --upgrade pip` و تلاش مجدد |
| PyInstaller خطای `No module named ...` | `python -m pip install pyinstaller` دوباره؛ مطمئن شوید CMD در پوشه‌ی `connector` است |
| آنتی‌ویروس exe را پاک کرد | False Positive است — در آنتی‌ویروس پوشه‌ی `dist` را Exclude کنید |
| exe اجرا شد ولی آیکون نیامد | نسخه‌ی دیباگ بسازید (بخش ۸) و پیام خطا را ببینید |
| خطای `tkinter` | نصب Python را Modify کنید و مطمئن شوید Tcl/Tk نصب است (پیش‌فرض هست) |

## ۸. ساخت نسخه‌ی دیباگ (اختیاری — برای دیدن خطاها)

اگر `ZhaniyaTray.exe` بی‌صدا کار نکرد، یک نسخه‌ی کنسول‌دار بسازید:

```
python -m PyInstaller --noconfirm --onefile --console --name ZhaniyaTray_debug tray_app.py
```

بعد `dist\ZhaniyaTray_debug.exe` را **از داخل CMD** اجرا کنید تا پیام خطاها را ببینید.
پیام‌های خطای برنامه در فایل `tray_error.log` (کنار exe) هم ثبت می‌شوند.
