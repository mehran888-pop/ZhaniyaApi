## بخش ۱ — نصب PHP

### 🔹 روش الف) XAMPP — آسان‌ترین و توصیه‌شده (ویندوز)

XAMPP یک بسته‌ی آماده است که PHP + وب‌سرور Apache + MySQL را با هم نصب می‌کند.

1. به سایت <https://www.apachefriends.org> بروید و نسخه‌ی **ویندوز** را دانلود کنید.
2. فایل نصبی را اجرا کنید (روی Next بزنید؛ نیازی به تغییر چیزی نیست).
   پیش‌فرض نصب: `C:\xampp`
3. بعد از نصب، برنامه‌ی **XAMPP Control Panel** را باز کنید و جلوی **Apache** دکمه‌ی **Start** را بزنید.
   (اگر MySQL هم می‌خواهید، جلوی MySQL هم Start بزنید — برای شروع با SQLite لازم نیست.)
4. تست: مرورگر را باز کنید و بروید به <http://localhost> — باید صفحه‌ی خوش‌آمد XAMPP دیده شود. ✅

> PHP همین‌جا نصب شد! مسیر آن: `C:\xampp\php\php.exe`

### 🔹 روش ب) PHP خام (ویندوز — برای اجرای سبک بدون Apache)

1. به <https://windows.php.net/download> بروید و آخرین نسخه‌ی **VS16/VS17 x64 Non Thread Safe ZIP** را دانلود کنید.
2. فایل ZIP را در مسیر `C:\PHP` باز کنید.
3. داخل آن پوشه، فایل `php.ini-development` را کپی کنید و نام نسخه‌ی کپی را بگذارید `php.ini`.
4. (اختیاری) برای اجرای `php` از هر مسیری: `C:\PHP` را به متغیر محیطی PATH ویندوز اضافه کنید.
   - Settings → About → Advanced system settings → Environment Variables → Path → Edit → New → `C:\PHP`
5. تست: CMD را باز کنید و بزنید:

```bat
C:\PHP\php.exe -v
C:\PHP\php.exe -m
```

اگر نسخه‌ی PHP نمایش داده شد، نصب موفق بوده است.

### 🔹 روش ج) هاست اشتراکی (cPanel / DirectAdmin)

اکثر هاست‌ها **PHP از قبل نصب دارند**. کافی است وارد cPanel شوید و بخش
«Select PHP Version» را نگاه کنید — نسخه‌ی **۸.۱ یا بالاتر** را انتخاب کنید.
هیچ کار دیگری لازم نیست؛ به بخش ۲ بروید.

### 🔹 روش د) سرور لینوکسی (VPS)

```bash
sudo apt update
sudo apt install php-cli php-sqlite3 php-mysql php-mbstring -y
php -v
```

### ✅ بررسی نهایی نصب PHP

در CMD (یا ترمینال) این دستور را بزنید:

```bash
php -m
```

باید این موارد در لیست باشند:

| اکستنشن | برای چیست | اگر نبود |
|---|---|---|
| `pdo_sqlite` یا `sqlite3` | دیتابیس آسان (SQLite) | در php.ini خط `extension=pdo_sqlite` را از حالت کامنت خارج کنید |
| `pdo_mysql` | دیتابیس MySQL (تولید) | در php.ini خط `extension=pdo_mysql` را باز کنید |
| `mbstring` | متن فارسی | در php.ini خط `extension=mbstring` را باز کنید |
| `openssl` | امنیت/توکن | معمولاً فعال است |

> خودِ ویزارد نصب (`setup.php`) هم در مرحله‌ی اول همه‌ی این‌ها را برایتان
> چک می‌کند و نتیجه را سبز/قرمز نشان می‌دهد — نگران حفظ‌کردن نباشید!

## بخش ۲ — فایل‌های برنامه را از کجا بگیرم و کجا بگذارم؟

> 🌐 **سناریوی رایج:** داشبورد روی **هاست** نصب شده (همین بخش) و می‌خواهید
> از سیستم فروشگاه از طریق **API نرم‌افزار ژانیا** به آن وصل شوید:
> 1. در داشبورد هاست وارد شوید → صفحه‌ی **«دستگاه‌ها»** → «ساخت دستگاه» → کلیدها نمایش داده می‌شود.
> 2. در همان صفحه، فرم **«ساخت config.json کانکتور»** را پر کنید
>    (نحوه‌ی اتصال: *API نرم‌افزار ژانیا* + آدرس ZhaniyaApi + کاربر/رمز ژانیا) و دانلود کنید.
> 3. روی سیستم فروشگاه: Python + پوشه‌ی `connector` + همان `config.json` → بخش ۵ همین راهنما.

### دریافت فایل‌ها

- از صفحه‌ی مخزن در گیت‌هاب، دکمه‌ی **Code → Download ZIP** را بزنید.
- فایل ZIP را باز کنید. آنچه نیاز دارید، پوشه‌ی **`cloud`** است (برای سیستم
  فروشگاه بعداً پوشه‌ی **`connector`** را هم لازم دارید).

### ساختار پوشه‌ها — این نقشه را نگه دارید

```
ZhaniyaApi/                  ← پوشه‌ی اصلی (از ZIP باز شده)
├── cloud/                   ← ★ کل داشبورد مدیریت — این را بارگذاری می‌کنیم
│   ├── public/              ← ★ ریشه‌ی وب‌سایت (Document Root باید به اینجا اشاره کند)
│   │   ├── setup.php        ← ویزارد نصب
│   │   ├── login.php        ← صفحه‌ی ورود
│   │   ├── dashboard.php    ← داشبورد
│   │   └── ...
│   ├── src/                 ← کدهای داخلی (حتماً باید باشد)
│   ├── config.php           ← تنظیمات (توسط ویزارد ساخته/پر می‌شود)
│   ├── seed_demo.php        ← سازنده‌ی داده‌ی نمونه
│   └── schema.*.sql         ← اسکیمای دیتابیس (کمکی — نصب بدون آن هم کار می‌کند)
└── connector/               ← ★ اپ رابط فروشگاه (روی سیستم ژانیا نصب می‌شود)
    ├── zhaniya_connector.py
    ├── config.example.json
    └── install_service.bat
```

> ⚠️ **مهم:** ساختار داخلی `cloud` را به‌هم نریزید و فایل‌ها را جابه‌جا نکنید.
> فقط کل پوشه‌ی `cloud` را در جای درست بگذارید.

### 🔸 حالت ۱: نصب روی همان رایانه (XAMPP) — برای تست یا تک‌شعبه

1. کل پوشه‌ی `cloud` را کپی کنید به:

```
C:\xampp\htdocs\zhaniya-cloud
```

2. در مرورگر باز کنید:

```
http://localhost/zhaniya-cloud/public/setup.php
```

3. ویزارد نصب را انجام دهید (بخش ۳). تمام!

> برای دسترسی سایر سیستم‌های داخل مغازه/شبکه، به‌جای `localhost` از IP همان
> کامپیوتر استفاده کنید (مثلاً `http://192.168.1.10/zhaniya-cloud/public/`).

### 🔸 حالت ۲: هاست اشتراکی (دسترسی از هرجا — پیشنهادی برای مدیریت چندشعبه)

1. وارد **cPanel → File Manager** شوید.
2. کل پوشه‌ی `cloud` را آپلود کنید داخل `public_html` (درست مثل کپی‌کردن).
   ساختار نهایی:

```
public_html/
└── cloud/
    ├── public/
    ├── src/
    ├── config.php
    └── ...
```

3. آدرس نصب:

```
https://دامنه‌ی-شما.com/cloud/public/setup.php
```

4. **(توصیه‌ی امنیتی)** اگر هاستتان اجازه می‌دهد، Document Root دامنه/زیردامنه
   را روی پوشه‌ی `cloud/public` تنظیم کنید تا فایل‌های داخلی دیده نشوند.
   (فایل `cloud/.htaccess` که در مخزن هست، در حالت معمولی هم دسترسی مستقیم
   به فایل‌های داخلی را می‌بندد.)

### 🔸 حالت ۳: سرور لینوکسی (VPS) با PHP داخلی

```bash
git clone https://github.com/mehran888-pop/ZhaniyaApi.git /var/www/zhaniya
cd /var/www/zhaniya/cloud
php seed_demo.php                  # اختیاری — داده‌ی نمونه
php -S 0.0.0.0:8080 -t public      # اجرای موقت برای تست
```

برای اجرای دائمی، Apache یا Nginx را طوری تنظیم کنید که Document Root روی
`/var/www/zhaniya/cloud/public` باشد.

## بخش ۳ — نصب داشبورد با ویزارد (۴ مرحله، ۲ دقیقه)

1. آدرس `setup.php` را در مرورگر باز کنید (آدرس‌های بالا).
2. **مرحله‌ی ۱ — بررسی سیستم:** همه‌ی ردیف‌ها باید سبز ✅ باشند. اگر قرمز بود،
   همان ردیف به شما می‌گوید چه چیزی کم است. «ادامه» را بزنید.
3. **مرحله‌ی ۲ — پایگاه‌داده:**
   - برای شروع: **SQLite** را بگذارید بماند (هیچ پیکربندی لازم نیست).
   - برای استفاده‌ی جدی/چندکاربره: **MySQL** را انتخاب و اطلاعات هاست/کاربر/رمز
     MySQL را وارد کنید و «تست اتصال» را بزنید.
4. **مرحله‌ی ۳ — مدیر و دستگاه:**
   - نام کاربری و رمز دلخواه برای ورود به داشبورد بسازید (حداقل ۸ کاراکتر).
   - کلیدهای دستگاه به‌صورت خودکار تولید شده‌اند؛ دست نزنید.
   - تیک «داده‌ی نمونه» را بزنید تا نمودارها از اول خالی نباشند.
5. **مرحله‌ی ۴ — پایان:** 🎉
   - دکمه‌ی **«دانلود config.json کانکتور»** را بزنید — این فایل را نگه دارید؛
     در بخش ۵ روی سیستم فروشگاه لازمش دارید.
   - «ورود به داشبورد» را بزنید و با رمز خودتان وارد شوید.

## بخش ۴ — نصب Python روی سیستم فروشگاه (برای کانکتور)

روی **همان رایانه‌ای که نرم‌افزار ژانیا نصب است**:

1. از <https://www.python.org/downloads/> نسخه‌ی ویندوز پایتون را دانلود کنید.
2. نصبی را اجرا کنید و ⚠️ حتماً تیک گزینه‌ی **«Add python.exe to PATH»** را
   در همان صفحه‌ی اول بزنید (خیلی مهم!).
3. بعد از نصب، CMD را باز کنید و بزنید:

```bat
python --version
```

اگر نسخه نشان داده شد (مثلاً `Python 3.12.x`)، آماده است.

## بخش ۵ — نصب کانکتور روی سیستم فروشگاه

1. پوشه‌ی **`connector`** را از ZIP بیرون بیاورید و در مسیری مثل
   `C:\ZhaniyaConnector` کپی کنید.
2. فایل **`config.json`** را که در مرحله‌ی ۴ ویزارد دانلود کردید، در همین پوشه
   بگذارید (کنار `zhaniya_connector.py`).
3. اتصال را تست کنید:

```bat
cd C:\ZhaniyaConnector
python zhaniya_connector.py --config config.json
```

اگر پیام «ارسال موفق» دیدید، همه‌چیز درست است. (Ctrl+C برای توقف تست.)

4. **نصب به‌عنوان سرویس ویندوز** (تا با هر بار روشن‌شدن کامپیوتر خودکار اجرا شود):
   - فایل [`nssm.exe`](https://nssm.cc/download) را دانلود و داخل همان پوشه‌ی
     `C:\ZhaniyaConnector` بگذارید.
   - روی فایل **`install_service.bat`** راست‌کلیک کنید → **Run as administrator**.
   - تمام! سرویس نصب و شروع می‌شود.

### اگر نرم‌افزار ژانیا را هم می‌خواهید وصل کنید

در `config.json` مقدار `mode` را تغییر دهید:

| مقدار | توضیح |
|---|---|
| `"demo"` | داده‌ی آزمایشی (برای تست داشبورد) |
| `"api"` | اتصال به ZhaniyaApi روی همان سیستم (`http://127.0.0.1/ZhaniyaApi`) — نام کاربری/رمز ژانیا را در بخش `api` وارد کنید |
| `"sqlserver"` | خواندن مستقیم دیتابیس `ZhaniyaDB` — ابتدا `pip install pyodbc` و رشته‌ی اتصال را در بخش `sql` کامل کنید |

## بخش ۶ — عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| `php نام داخلی یا خارجی نیست` (php is not recognized) | مسیر PHP به PATH اضافه نشده — بخش ۱ روش ب، مرحله‌ی ۴ |
| صفحه‌ی `setup.php` باز نمی‌شود (404) | مسیر فایل‌ها اشتباه است — مطمئن شوید فایل در `public/setup.php` است و آدرس دقیقاً `.../public/setup.php` است |
| «✗ نیازمند بررسی» در مرحله‌ی ۱ | اکستنشن PHP خاموش است — php.ini را باز کنید و خط همان اکستنشن را از `;` دربیاورید، بعد Apache را Restart کنید |
| خطای `could not find driver` | اکستنشن `pdo_sqlite` یا `pdo_mysql` فعال نیست |
| `نصب قبلاً انجام شده است` | فایل `data/install.lock` داخل پوشه‌ی cloud را حذف کنید تا نصب مجدد ممکن شود |
| `خطای نصب (مرحله‌ی ...)` | پیام دقیقاً می‌گوید کدام مرحله مشکل داشته؛ متن آن را بخوانید |
| کانکتور: `403 دستگاه ناشناخته` | `device_key`/`device_secret` در `config.json` با آنچه ویزارد داده یکسان نیست |
| کانکتور: `408 اختلاف ساعت` | ساعت ویندوز را با اینترنت همگام کنید (Time → Sync now) |
| کانکتور: `401 امضای نامعتبر` | `device_secret` اشتباه است یا `cloud_url` درست نیست |
| داشبورد داده نشان نمی‌دهد | ابتدا داده‌ی نمونه را بزنید یا کانکتور را اجرا کنید؛ بعد صفحه‌ی «دستگاه‌ها» وضعیت اتصال را نشان می‌دهد |

## بخش ۷ — کارهای امنیتی بعد از نصب

1. رمز کاربر `admin` را قوی بگذارید.
2. در `cloud/config.php` مقدار `app_secret` را به یک رشته‌ی تصادفی بلند تغییر دهید.
3. روی هاست واقعی حتماً **HTTPS** فعال کنید (هاست‌های اشتراکی معمولاً
   رایگان Let's Encrypt دارند).
4. برای آرامش خاطر، بعد از نصب می‌توانید فایل `public/setup.php` را حذف کنید
   (یا بگذارید بماند — خودش با قفل `install.lock` غیرفعال می‌شود).
