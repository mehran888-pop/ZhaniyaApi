# ژانیا کلود — داشبورد مدیریت فروش + کانکتور بدون نیاز به IP ثابت

این مخزن شامل:

1. **`bin/ZhaniyaApi.dll`** — API نرم‌افزار ژانیا (ASP.NET Web API — فقط باینری)
2. **`cloud/`** — اپ مدیریتی وب (PHP) با داشبورد حرفه‌ای، نمودار و گزارش‌ها
3. **`connector/`** — اپ رابط (Agent) که روی سیستم فروشگاه اجرا می‌شود و بدون
   نیاز به IP ثابت، داده‌ها را به سرور ابری می‌فرستد
4. **`docs/api-review.fa.md`** — بررسی فنی API ژانیا و نقاط قوت/ضعف آن

## معماری

```
┌────────────────────────── فروشگاه ──────────────────────────┐
│  نرم‌افزار ژانیا ── SQL Server (ZhaniyaDB)  /  ZhaniyaApi     │
│                       │                                       │
│              Zhaniya Connector (Python)                       │
│              صف آفلاین + امضای HMAC                           │
└───────────────────────┬─────────────────────────────────────┘
                        │  HTTPS فقط به بیرون (outbound)
                        │  ← بدون IP ثابت / بدون پورت‌فوروارد
                        ▼
┌────────────────── سرور ابری (PHP) ─────────────────────────┐
│  api/ingest.php ← دریافت داده‌ی دستگاه‌ها                    │
│  MySQL / SQLite ← ذخیره‌ی فاکتور، اقلام، اعتباری‌ها          │
│  داشبورد مدیریت (RTL، فارسی، Chart.js)                      │
│   • گزارش فروش از تاریخ تا تاریخ                             │
│   • گزارش اقلام فروش رفته                                    │
│   • گزارش اعتباری‌ها                                         │
│   • گزارش لحظه‌ای (به‌روزرسانی خودکار)                        │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 نصب آسان (Setup)

سه راه دارید — از آسان‌ترین:

### راه ۱ — ویزارد نصب تحت وب (روی هاست)
1. پوشه‌ی `cloud/` را روی هاست PHP آپلود کنید (پوشه‌ی `public` در داک‌روت وب‌سرور).
2. در مرورگر باز کنید: **`http://YOUR-SERVER/setup.php`**
3. ویزارد ۴ مرحله‌ای را دنبال کنید:
   بررسی سیستم ← پایگاه‌داده (SQLite بدون پیکربندی یا MySQL) ← حساب مدیر + کلید دستگاه ← پایان.
4. در پایان، فایل **`config.json` کانکتور** را دانلود و روی سیستم فروشگاه اجرا کنید.

> پس از نصب، فایل `data/install.lock` ساخته می‌شود و ویزارد دیگر اجرا نمی‌شود.

### راه ۲ — یک دستور (روی سیستم محلی)
```bash
python setup.py            # منوی تعاملی فارسی (ویندوز: setup.bat | لینوکس/مک: setup.sh)
python setup.py --demo     # نصب سریع دمو + اجرای داشبورد با یک دستور
python setup.py --check    # بررسی پیش‌نیازها
```

### راه ۳ — نصب دستی
```bash
cd cloud
php seed_demo.php            # ساخت کاربر admin و داده‌ی نمونه
php -S 0.0.0.0:8080 -t public
```

سپس `http://localhost:8080` را باز کنید:

| نام کاربری | رمز عبور |
|---|---|
| `admin` | `admin123` |

> ⚠️ در استقرار واقعی حتماً رمز را تغییر دهید و `app_secret` را در
> `cloud/config.php` مقداردهی کنید.

### استقرار با MySQL (تولید)

```bash
mysql -u root -p -e "CREATE DATABASE zhaniya_cloud CHARACTER SET utf8mb4"
mysql -u root -p zhaniya_cloud < cloud/schema.mysql.sql
export ZH_DB_DRIVER=mysql ZH_DB_HOST=... ZH_DB_NAME=zhaniya_cloud \
       ZH_DB_USER=... ZH_DB_PASS=... ZH_APP_SECRET=...
php -S 0.0.0.0:8080 -t cloud/public   # یا Apache/Nginx + php-fpm
```

## راه‌اندازی کانکتور فروشگاه

```bash
cd connector
cp config.example.json config.json     # ویرایش: cloud_url و کلیدهای دستگاه
python zhaniya_connector.py --config config.json
```

**⭐ برنامه‌ی ویندوزی (آیکون کنار ساعت):** با اجرای یک‌بار `connector/build_exe.bat`
فایل اجرایی `ZhaniyaTray.exe` ساخته می‌شود — برنامه‌ای در system tray با داشبورد
تنظیمات (نام کاربری/رمز)، اجرای خودکار همراه ویندوز و مدیریت کانکتور.

**سرویس ویندوز (بدون دستور):** فایل [`connector/install_service.bat`](connector/install_service.bat) را
روی سیستم فروشگاه یک‌بار با دسترسی Administrator اجرا کنید تا کانکتور به‌صورت
خودکار با هر بار روشن شدن ویندوز اجرا شود.

جزئیات بیشتر: [`connector/README.md`](connector/README.md)

برای ثبت دستگاه در سرور ابری، یک ردیف در جدول `devices` بسازید
(`device_key` و `secret` تصادفی و قوی) و همان مقادیر را در `config.json`
کانکتور قرار دهید. وضعیت اتصال دستگاه‌ها در صفحه‌ی «دستگاه‌ها» قابل مشاهده است.

## گزارش‌ها

| صفحه | محتوا |
|---|---|
| داشبورد | KPIهای امروز/بازه، نمودار روند فروش، ترکیب پرداخت، پرفروش‌ترین‌ها، فید لحظه‌ای |
| گزارش فروش و اقلام | فروش از تاریخ تا تاریخ (نمودار + جدول)، اقلام فروش رفته، خروجی CSV |
| گزارش اعتباری‌ها | فروش اعتباری/دریافتی/مانده بدهی هر مشتری، کارتکس، نمودار روزانه |
| گزارش لحظه‌ای | فروش ساعتی، جریان زنده‌ی فاکتورها (هر ۱۰ ثانیه)، وضعیت اتصال |
| دستگاه‌ها | آخرین ارتباط کانکتورها، لاگ همگام‌سازی |

تاریخ‌ها را می‌توانید هم به‌صورت جلالی (`1405/08/13`) و هم میلادی وارد کنید.

## امنیت

- اتصال کانکتور **outbound** است؛ روی مودم فروشگاه هیچ پورتی باز نمی‌شود.
- هر بسته‌ی داده با `HMAC-SHA256` امضا و در برابر replay محافظت می‌شود.
- ورود مدیر با نشست امن + CSRF محافظت می‌شود.
- در تولید: HTTPS اجباری، رمز قوی دستگاه‌ها و `ZH_APP_SECRET` اختصاصی.
